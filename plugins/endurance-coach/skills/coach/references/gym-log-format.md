# Gym Log Template

Filename: `YYYY-MM-DD-[split-name].md`. One file per session in `gym/`.
Read the active strength plan + working weights from `strength-log.md` and gear from `equipment.md` before generating.
When the session is done and reviewed, prefix the filename with `✅`.

```markdown
# [Split Name] — [Day Mon DD]

> [running context for today and tomorrow]

---

## [Exercise Name]
**[Weight] × [Reps]** (RPE [target])
- [ ] Set 1
- [ ] Set 2
- [ ] Set 3
> _Actual weight if different:_

---

Notes:

Start Garmin "Strength" when you begin
When done: tell coach "done with gym"
Swapped exercise? Write the new one + weight used
```
