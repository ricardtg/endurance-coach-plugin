# Plan Evaluation Criteria

Check each criterion when evaluating an external plan.

## 1. Volume Compatibility
- Plan's weekly volume vs athlete's current/recent volume
- Flag week 1 exceeding current by >30%
- Flag peak exceeding all-time peak by >20% without progressive build
- Recovery/down weeks every 3-4 weeks?

## 2. Pace/HR Zone Alignment
- Convert plan's prescriptions to absolute values using athlete's data
- Flag easy zones too high (above VT1) or too low (below conversational)
- Flag plans with no zone specification

## 3. Workout Appropriateness for Distance
- 5K: VO2max intervals + reps. Long runs >60 min unnecessary.
- 10K: VO2max + threshold. Long runs 60-75 min.
- HM: threshold primary + VO2max + HM-pace segments.
- Marathon: MP long runs, progressive runs, threshold. Fueling mandatory.

## 4. Recovery and Taper
- 5K/10K: 7-10 days. HM: 10-14 days. Marathon: 14-21 days.
- Maintains intensity, reduces volume? (Mujika)
- Rest days between quality sessions?

## 5. Timing Compatibility
- Duration vs available time
- Post-race recovery accounted for?
- Schedule conflicts?

## 6. Strength Integration
- Accounts for concurrent strength?
- Scheduling conflicts (heavy squats before VO2max intervals)?
- If missing: note gap, recommend strength overlay

## 7. Missing Elements
- Fueling (mandatory for marathon)
- Strength periodization
- Adjustment/bail-out rules

## Output
Conversational summary. Cite plan's numbers vs athlete's. Verdict: use as-is, modify (list changes), or reject (explain).
