# Distance-Specific Block Structures

## 5K (4-8 weeks)
- **Primary**: VO2max intervals (I pace, 800-1200m) + Repetition (R pace, 200-400m)
- **Secondary**: Threshold
- **Long runs**: 45-60 min, easy
- **Quality**: 2/week
- **Volume**: 70-80% of comfortable. Intensity-focused.
- **Taper**: 7-10 days. Maintain I/R, drop volume 40%.

## 10K (6-8 weeks)
- **Primary**: VO2max intervals (I pace, 800-1200m, progress to mixed)
- **Secondary**: Threshold (15-25 min continuous) + RP rehearsals (weeks 5-6)
- **Long runs**: 60-75 min, easy
- **Quality**: 2/week
- **Volume**: 75-90% of comfortable
- **Taper**: 7-10 days

## Half Marathon (8-12 weeks)
- **Primary**: Threshold/tempo (building 20→30-40 min continuous, or cruise intervals)
- **Secondary**: VO2max 1/week + HM-pace long run segments
- **Long runs**: 90-110 min. HM-pace segments in final 6-8km weeks 6-10.
- **Quality**: 2/week
- **Volume**: 85-100% of comfortable
- **Taper**: 10-14 days

## Marathon (12-18 weeks)
- **Primary**: MP long runs (8km→16-20km at MP) + Threshold
- **Secondary**: VO2max 1/week early, biweekly late
- **Long runs**: build to 32-37km. MP blocks from week 4-5. Fueling mandatory >20km.
- **Quality**: 2/week
- **Volume**: Progressive, max 10%/week. Recovery weeks every 3-4.
- **Taper**: 14-21 days
- **Fueling**: Non-negotiable. Gel timing in plan. Build toward 60-90g/hr.

## Recovery Ramp-Up (Post-Race)

| Previous Race | Min Recovery Before Intensity |
|--------------|-------------------------------|
| 5K | 3-5 days |
| 10K | 5-7 days |
| Half Marathon | 10-14 days |
| Marathon | 14-21 days |

Protocol: rest → easy 40-50% volume → fartlek (effort-based) → structured intervals.
