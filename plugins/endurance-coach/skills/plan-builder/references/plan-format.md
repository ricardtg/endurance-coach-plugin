# Plan Output Format

Write as standalone markdown in `<coach_dir>/plans/`. Filename: `<distance>-plan-<target>.md`.

## Required Sections

### Header
- Athlete name, duration, target race + date, goal (safe + ambitious)
- Context (where athlete is coming from)
- Methodology citation

### Training Paces Table
- All zones: pace range, HR range, purpose
- Working VDOT
- Validation notes + Garmin LT cross-reference

### Weekly Template
- Training days, quality days, strength placeholder days, rest days

### Week-by-Week Sessions
Per week:
- Phase label (recovery, rebuild, specificity, sharpening, taper)
- Day-by-day sessions with prescriptions
- **Strength placeholder rows** ("Strength: Lower A (see strength plan)")
- Weekly volume range
- Intensity summary
- Checkpoints where applicable

### Volume & Intensity Summary Table
One row per week: phase, volume, quality sessions, strength frequency.

### Race Day Plan
- Pacing by km segment (pace + expected HR)
- Pre-race nutrition and warmup
- Mental cues per segment
- Actual race distance factored in

### Adjustment Rules
- Quality session too hard / can't complete reps
- Persistent fatigue (RHR elevated 3+ days)
- Paces too easy (recalibrate upward)
- Injury/pain
- Strength interference
- Schedule disruptions

### Methodology Notes
3-5 paragraphs on key design decisions.

## Strength Overlay (in every race plan)
1. Strength sessions/week per phase
2. Placeholder rows in weekly tables
3. Sequencing rules (no heavy lower within 24h of quality running)
4. Taper: maintain intensity, reduce lower body volume. Last heavy lower 7-10 days pre-race. Upper continues.
5. Cross-reference: "See strength-endurance skill for gym programming."
