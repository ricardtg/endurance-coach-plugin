# Exercise Library — Strength-Endurance

Check equipment.md before prescribing. If primary unavailable, use alternative. Never prescribe exercises on the athlete's avoid list.

| Hinge | Trap Bar Deadlift | Romanian Deadlift | Hip Hinge Machine |

| Shoulder health | Face Pull | Band Pull-apart | External Rotation |

## Injury/Restriction Protocol

- Check injury table in athlete-profile.md
- Apply exercise restrictions using alternatives above
- If unsure whether exercise is safe → flag and recommend physio
- Shoulder issues: prefer DB bench over barbell, skip OHP until cleared, prioritize face pulls
- Knee issues: consider box squat, reduce depth, add leg curl volume
- Lower back issues: trap bar DL over conventional, avoid loading spine in flexion
